# Fantasia
Fantasia is a shaderpack for both VR and PC,
meant to give mostly your recordings a 
fantasy vibe. Looks best on PC.

# FantasiaFoliage
An experimental VR and PC mod, which makes 
the leaves in most maps move.
Mainly focused on forest.

# Installation
*Make sure to install every shaderpack in the ReShade installation*

**Download and extract the mod into your ./BepInEx/plugins folder**

FANTASIA PC INSTALLATION
1. Find ReShade.ini in your *./Gorilla tag* folder
2. Open the file
3. Change *PresetPath=.* to *PresetPath=fantasia.ini*.
4. Save the file.

FANTASIA VR INSTALLATION
1. Find ReShadeVR.ini in your *./Gorilla Tag* folder
2. Open the file
3. Change *PresetPath=.* to *PresetPath=./fantasiavr.ini*
4. Save the file.
